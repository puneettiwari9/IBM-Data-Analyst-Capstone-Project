# IBM Data Analyst Capstone Project 📊

## 📌 Project Overview
This repository contains the final capstone project for the **IBM Data Analyst Professional Certificate** (11 Courses, 22 Exams, A+ Grade). 

The project analyzes the **Stack Overflow Developer Survey** dataset to uncover current technology usage, future technology preferences, and developer demographics. It includes data cleaning, exploratory data analysis (EDA), visualizations, and an interactive dashboard.

## 🎯 Objectives
- Clean and preprocess real-world survey data (handling missing values and duplicates).
- Analyze programming language and database trends (Current vs. Future).
- Build an interactive dashboard to visualize technology stacks.
- Present actionable, data-driven insights for developers, recruiters, and organizations.

## 🛠️ Tools & Technologies Used
- **Python (Pandas, Matplotlib, Seaborn):** For data wrangling, cleaning, and generating static visualizations.
- **SQL (SQLite):** For querying the database and extracting specific insights.
- **Excel:** For initial data handling and previewing.
- **Looker Studio:** For building a 3-tab interactive dashboard (Current Tech, Future Trends, Demographics).

## 📊 Key Findings
- **Python's Massive Surge:** While JavaScript and MySQL lead in *current* usage, **Python** and **PostgreSQL** are the most desired technologies for the *future*, signaling a shift towards AI, Data Science, and scalable architectures.
- **Cloud Dominance:** Amazon Web Services (AWS) remains the top platform both currently and for future use.
- **Market Fragmentation:** A massive "Others" category in the charts indicates that developers rely on highly diverse, niche tools rather than a uniform stack.
- **Demographic Influence:** The majority of respondents are young (25-34 years) and highly educated (Bachelor's/Master's degrees), primarily from the US and India.
